# 贵州省红色研学可视化地图
> 基于高德地图JS API的红色文旅研学数字化服务平台

## 🎯项目简介
本项目聚焦贵州省红色文化资源，利用Web地图可视化技术，整合省内红色研学点位数据，开发交互式红色研学地图。
旨在助力中小学生、企事业单位规划红色研学路线，推动红色文化数字化传播。

## 🌐线上预览地址
👉 https://liaojunfan.github.io/red-travel-map/map2.html
👉 https://liaojunfan.github.io/red-travel-map/ai_chat.html

## 🛠️技术栈
前端：HTML5、JavaScript、CSS
地图服务：高德地图 JS API 2.0
数据源：贵州省红色景点调研数据集（reddata.csv）

## 📁项目文件说明
- index.html — 项目首页
- map.html — 交互式研学地图主页面
- app.py — Python后端数据处理脚本
- reddata.csv — 红色研学点位原始数据集
- ai_chat.html — 黔南红色研学AI助手页面

## 💻本地部署教程
1. 克隆或下载仓库全部代码
2. 使用本地Web服务器启动项目
3. 浏览器访问 map.html

## ✨核心功能
1. 全省红色研学点位可视化标记
2. 点位详情弹窗展示景点介绍
3. 地图拖拽缩放浏览
4. 研学路线规划辅助查询
